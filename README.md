# $H^2$ Bot

学生有问题讲不明白时，可以在这里继续问。项目名里的两个 H 指 Help 和 Higher Understanding：先把卡住的地方讲清楚，再说清它为什么是这样，而不是只给一个答案。

页面在仓库根目录，接口在 `server/`。浏览器只访问本仓库的接口。账号、会话和登录状态存在 PostgreSQL 里。回答由 `.env` 配置的 FastGPT 应用生成，密钥不进前端。当前会话 id 记在 URL 里，刷新和后退都会回到这个会话。回答中途断了，已生成的部分文字在 Redis 保留一段时间，刷新后可以续上。

## 功能

用账号登录。登录状态存在 `login` cookie 里，请求都会带上；一段时间没有任何请求后需要重新登录。

登录后可以新建会话、查看历史消息、继续提问。回答生成期间界面显示加载动画，答案到达后整段显示，不逐字输出。助手回答按 Markdown 排版：标题、列表、表格、代码块都照 Markdown 显示，链接能点；公式按 LaTeX 排出来（`$...$` 和 `$$...$$`）；图片只给一个链接，不去加载。等待回答时发送按钮变成停止按钮，点击后本轮立即结束，已生成的部分保留。刷新页面能恢复正在进行的这一轮：提问、加载状态和部分回答都在。回答生成失败时，回答下面会写明失败原因，并给一个「重试」按钮，点一下把这一轮重新答一遍，历史里不会出现两遍问答。界面语言支持简体中文、繁体中文和英语，选择记录在账号上。

左侧是会话列表。新会话发出第一条消息后才进入列表；URL 没有会话 id 时，页面停在新建对话的空白状态。每条会话可以重命名、删除或置顶。置顶时页面把时间交给接口保存；接口返回的列表仍按创建时间排，由页面把先置顶的排在前面。删除会话时也会请求 FastGPT 删除对应记录。

窄屏幕下会话列表收起，从侧边滑出。接口连不上时页面留在当前位置并提示稍后重试，不会跳回登录页。

## 本地运行

工具版本和 Git 钩子见 [docs/TECH.md](docs/TECH.md)，实测与文档不一致的地方见 [docs/FINDINGS.md](docs/FINDINGS.md)。

先在本机装好 PostgreSQL 和 Redis 并确认它们在运行。然后在仓库根目录准备 `.env`：复制 `.env.example`，填上自己的 FastGPT、数据库和 Redis 连接信息。

仓库根目录执行：

```bash
pnpm install
pnpm run dev:frontend
pnpm run dev:backend
```

前后端是两个进程，需要开两个终端分别跑。页面开发服务器起来后，浏览器访问它的地址。接口监听 `127.0.0.1:3001`，页面把 `/api` 转发到这里。

第一次要建表和初始账号，在 `server/` 里执行：

```bash
uv run python -m server.db.init
```

这条命令只创建缺失的表和列。账号已存在时不改密码，也不清除已有会话。初始账号的用户名和密码写在 `server/src/server/db/init.py`。

Python 命令统一在 `server/` 目录下用 `uv run` 执行，不要在仓库根目录直接用 `python` 或 `pip`。
