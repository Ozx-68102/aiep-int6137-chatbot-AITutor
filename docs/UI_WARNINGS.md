# 界面上的提示放在哪里

页面上出提示的地方只有三种，各有各的位置。不要再新增第四种。

先把页面上那几块地方叫清楚：

- **聊天记录**：中间那一片对话气泡（用户问的、助手答的）。
- **输入区**：底下那个输入框和发送按钮。
- **弹窗**：盖在页面上的小窗口（重命名、删除、退出登录、设置）。

## 输入区上方：出错了、有状况

跟这一场对话有关、又需要用户知道的事，放在输入区分隔线上方的警示框（`src/components/chat/WarningBox.tsx` 里的 `WarningBox`）：

警示框跟本页所有提示面一样是白底黑字，语气只由左侧图标表达（颜色规则见「写新的提示时」第 4 条）。

- 红色 `CircleAlert` 图标：出错了 —— 操作没成功、连不上服务器。
- 琥珀色 `TriangleAlert` 图标：有状况 —— 服务降级（数据库、Redis 不可用）、停止没停住、这一场对话还有一轮在写。
- 会话失效警示条（2026-11-05 登记）：会话过期（401 带 `reason: expired`）用琥珀「有状况」语气 + 「重新登录」按钮，点击在原页面弹出重登录弹窗；账号被停用（`reason: disabled`）用红色出错语气、不给按钮（终态，登录也没用）。这一条不可关闭、发新一轮也收不掉，只有重新登录成功才撤下；进入/退出条件与恢复流程见 [CHAT_PAGE_BEHAVIOR.md](CHAT_PAGE_BEHAVIOR.md)「会话过期后留在原页面的状态」。

位置：警示框不在带 `border-t` 的输入区容器里面，而是聊天滚动区与输入区之间的流内兄弟节点——分隔线固定在输入区顶上不动，警示框坐在线的正上方，出现时压缩消息区高度（消息上滚）、不遮挡内容。多条警示框纵向堆叠。

轮次级的状态不走警示框：「对话已停止」「消息生成失败」在气泡下方的脚注里（见下面「聊天记录里」和 [MESSAGE_ACTIONS.md](MESSAGE_ACTIONS.md)），警示框只留会话级事件。

这个框不会自己消失：用户可以关掉它，发新的一轮也会把它收掉。例外：会话失效警示条不可关闭（见上）。

原来散在别处的提示都并到它这儿了：

- 顶部居中浮五秒的那个 Toast（连不上服务器时弹的）：删掉了，连不上服务器也走这个框。
- 聊天区顶部那个琥珀色常驻框（服务不可用）：并进来了。
- 聊天记录里那个灰色小药丸（「已停止生成」「这场对话还有一条正在回答」）：删掉了，后者现在是这个框；「已停止生成」后来又挪进了气泡下方的脚注（见下）。

连不上服务器只有这一个框：动作失败时不再另外报一条红色的。

## 聊天记录里：气泡下方的脚注

每个气泡（用户提问、助手回答）下方都挂同一个脚注（`src/components/chat/MessageActions.tsx` 里的 `MessageActions`）：一条常驻矮条，固定预留一小段高度，hover 型按钮出现时布局不跳动。跟某一轮有关的问题写在这一轮回答的脚注里——哪一轮出的问题，提示就放在哪一轮下面，始终可见、不可关闭（坏掉的轮次必须始终留着恢复的入口）：

- 失败轮：黄色 `CircleAlert` icon + 灰字「消息生成失败」（stone-500 灰系）+「重试」按钮。
- 被停轮：黑色 `CircleStop` icon（与输入区的停止按钮同一个）+ 灰字「对话已停止」+「重试」按钮——被停轮也有重试，跟失败轮的重试是同一条路（`POST /api/chat` + `retryOf`）。
- 重试按钮是黑色中性描边，不是红色的错误样式；点下去把这一轮重发一遍，旧回答连同脚注提示一起去掉，提问留在原处。
- 一个字都没写出来就失败/被停的轮次也有脚注：没有回答气泡，脚注挂在用户提问下方。
- 流式输出中的等待气泡（三个点）不挂脚注。

脚注里还有一个 hover 区（鼠标在气泡或脚注上时按钮淡入）：编辑、复制、点赞点踩将来进这里，第一期是空的。设计和分期见 [MESSAGE_ACTIONS.md](MESSAGE_ACTIONS.md)。

以前的「红色描边气泡」（往消息流里插一条 `role:'error'` 的合成消息）已退役：轮次级状态由消息自身的 `failed` / `aborted` 标志驱动，与轮次无关的错误（「无法连接到服务器」这类）统一归输入区上方的警示框，消息流里只留真正的对话内容。

## 弹窗里：表单自己的错误

重命名、删除、退出登录、设置这些弹窗里的错误，是表单自己的校验信息，用弹窗里的行内黑字加红色 `CircleAlert` 图标（`role="alert"`），弹窗不关。

## 成功之后：Toast

做成了、但界面上已经看不出变化的时候（改完名字弹窗就关了、删掉会话列表里就没了），用一个顶部居中的 Toast 告诉用户「成了」，三秒后自己消失（`src/components/toast/Toast.tsx`）。Toast 也是白底黑字，左侧一个绿色 `CircleCheck` 图标。

失败不走 Toast：失败要么留在弹窗里（弹窗还开着），要么进输入区上方的框。Toast 只报成功。

## 弹窗和 Toast 都有出现和消失的动画

弹窗（重命名、删除、设置、退出登录）和 Toast 出现时淡入、放大一点，消失时淡出、缩小一点，不要瞬间出现、瞬间消失。弹窗统一用 `src/components/shell/Modal.tsx` 那个壳：它负责进出动画、Esc 关闭、点背景关闭，各弹窗只管自己的内容。

## 写新的提示时

1. 先问它跟谁有关：跟这一场对话有关就放输入区分隔线上方，跟某一轮回答有关就放那个气泡下方的脚注里，跟某个弹窗里的输入有关就放弹窗里，做成了但看不出来就放 Toast。
2. 不要新造浮层（角标、居中弹窗、漂浮文字）。要更显眼就用输入区上方的警示框（error 语气）。
3. 三种语言都要有：简体中文、繁体中文、英文（`src/i18n.ts`）。
4. 颜色规则（2026-11-04 维护者决定）：提示面（警示框、行内表单错误、Toast、脚注）背景一律白（`bg-base-100`）、文字一律黑（`base-content`），语义色只允许出现在图标上：红 `text-error` 出错、琥珀 `text-warning` 有状况、绿 `text-success` 成功。不要用 `alert-error` / `alert-warning` / `alert-success` 这种整块语义色背景。
