# 界面上的提示放在哪里

页面上出提示的地方只有三种，各有各的位置。不要再新增第四种。

先把页面上那几块地方叫清楚：

- **聊天记录**：中间那一片对话气泡（用户问的、助手答的）。
- **输入区**：底下那个输入框和发送按钮。
- **弹窗**：盖在页面上的小窗口（重命名、删除、退出登录、设置）。

## 输入区上方：出错了、有状况

跟这一场对话有关、又需要用户知道的事，放在输入区的正上方
（`src/components/chat/WarningBox.tsx` 里的 `WarningBox`）：

- 红色：出错了 —— 操作没成功、连不上服务器。
- 琥珀色：有状况 —— 服务降级（数据库、Redis 不可用）、这一轮被停止、这一场对话还有一轮在写。

这个框不会自己消失：用户可以关掉它，发新的一轮也会把它收掉。

原来散在别处的提示都并到它这儿了：

- 顶部居中浮五秒的那个 Toast（连不上服务器时弹的）：删掉了，连不上服务器也走这个框。
- 聊天区顶部那个琥珀色常驻框（服务不可用）：并进来了。
- 聊天记录里那个灰色小药丸（「已停止生成」「这场对话还有一条正在回答」）：删掉了，这两条现在是这个框。

## 聊天记录里：跟某一条回答有关

跟某一条回答有关的问题，写在那条回答下面（红色描边的气泡）：「消息生成失败」这类。
哪一条出的问题，提示就贴在哪一条旁边。

## 弹窗里：表单自己的错误

重命名、删除、退出登录、设置这些弹窗里的错误，是表单自己的校验信息，用弹窗里的行内红字
（`role="alert"`），弹窗不关。

## 成功之后：Toast

做成了、但界面上已经看不出变化的时候（改完名字弹窗就关了、删掉会话列表里就没了），
用一个顶部居中的 Toast 告诉用户「成了」，三秒后自己消失（`src/components/toast/Toast.tsx`）。

失败不走 Toast：失败要么留在弹窗里（弹窗还开着），要么进输入区上方的框。Toast 只报成功。

## 弹窗和 Toast 都有出现和消失的动画

弹窗（重命名、删除、设置、退出登录）和 Toast 出现时淡入、放大一点，消失时淡出、缩小一点，
不要瞬间出现、瞬间消失。弹窗统一用 `src/components/shell/Modal.tsx` 那个壳：它负责进出动画、
Esc 关闭、点背景关闭，各弹窗只管自己的内容。

## 写新的提示时

1. 先问它跟谁有关：跟这一场对话有关就放输入区上方，跟某一条回答有关就放那条回答下面，
   跟某个弹窗里的输入有关就放弹窗里，做成了但看不出来就放 Toast。
2. 不要新造浮层（角标、居中弹窗、飘字）。要更显眼就用输入区上方的红框。
3. 三种语言都要有：简体中文、繁体中文、英文（`src/i18n.ts`）。
