## <span id="sec0">导入</span>

在开始之前，让我们先了解一下「前端三剑客」——也就是**HTML、CSS和JavaScript（即JS）**吧！其实，它们之间的关系可以用一个很直观的比喻来理解：HTML是前端的**骨架**，CSS负责完善**皮肤和外貌**，而JS是其中的**肌肉和神经**。



## <span id="sec1">HTML：网页的「结构」和「内容」</span>

HTML的全称是**HyperText Markup Language**，中文名是「**超文本标记语言**」，它负责定义网页的结构和内容。

它决定页面上**有什么**内容、**在哪里**呈现。比如说，标题、段落、图片和按钮等等。它使用一系列的**标签**来标记这些内容，例如`<h1>`是一级标题，`<p>`是段落，`<img>`是图片等等。

不过，值得注意的是，HTML是一种**标记语言**，不是**编程语言**。它的任务仅仅只是「标注」和「描述」内容的结构和含义，它**不具备**逻辑判断或者循环的能力。



## <span id="sec2">CSS：网页的「皮肤」和「外表」</span>

CSS的全称是**Cascading Style Sheets**，中文名是「**层叠样式表**」，它负责控制网页的外观和布局。

网页上所有好看的视觉效果和排版，都是CSS在发挥作用。文字颜色、字号大小、页面分栏，以及鼠标悬停在某个元素上有没有对应动画效果等等，都是它在控制。

既然它的名字里有「层叠」，那就意味着你可以用多种方式为同一个元素定义样式，浏览器会根据设定好的特定优先级规则来决定最终应用哪个样式，这为开发者在进行样式复用和精细控制提供了很大的灵活性。



## <span id="sec3">JavaScript：网页的「肌肉」和「神经」</span>

JavaScript没有中文名字，不过我们习惯叫它JS。它负责网页的行为和交互，是前端的「神奇魔法」。有了它，我们可以让网页从一个「静态文档」变成灵活的「动态应用」。

HTML和CSS构建的东西本质上只是一个静态的页面。内容不会自己变化，按钮点了也可能没有任何反应。而JS就给它们赋予了「生命力」。它能让网页响应用户的操作（如点击、输入和滚动等等），能动态修改页面上已有的HTML内容和CSS样式，不用刷新页面就能加载新内容，甚至能够控制音视频和2D/3D的图形渲染。

这里有一个**关键的区别**：HTML和CSS都**不是**严格意义上的「编程语言」，因为它们不包含逻辑控制能力；而**JS是一门真正的编程语言**，因为它本身具备完整的计算和逻辑能力。



## <span id="sec4">那它们是怎么协作的呢？</span>

举个例子，页面上有一个提交按钮。

- 由HTML把按钮「放」在页面上：`<button>提交</button>`，此时它还是一个静态的、没有任何反应的元素。
- CSS让它变得好看，比如加上圆角、颜色、阴影等等。
- 而JS能让按钮「活」起来：当用户点击它时，能弹出一个提示告诉你「提交成功」，并且让浏览器带你去下一个页面。

所以，一个完整的网页体验，是这三者**分层协作**的结果：HTML 提供结构（Structure），CSS 提供表现（Presentation），JavaScript 提供行为（Behavior）。
